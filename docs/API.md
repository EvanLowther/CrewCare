# API contract

Source of truth: [`backend/planit/models.py`](../backend/planit/models.py). The full schema is in
[`openapi.json`](openapi.json); browse it at http://localhost:8000/docs. Frontend types in
`frontend/src/lib/api-types.ts` are generated by `python dev.py types`. CI fails if they're out of date.

All times are ISO 8601 UTC. Site ids are EIA plant codes; sites managers create start at 9,000,000.

Send `Authorization: Bearer <Auth0 access token>` when signed in (see [AUTH.md](AUTH.md) for who may do what and
the sign-in routes). Without it, reads return only public reference sites.

| Method | Path | Returns | Notes |
|---|---|---|---|
| GET | `/api/health` | `Health` | `mock`, `database` status |
| GET | `/api/sites` | `SiteList` | Sites the viewer may see, highest risk first. Each has `is_reference`, `my_role`, `can_manage`, `can_delete`. `?hours_ahead=1..24` scores each site with its forecast for that hour |
| GET | `/api/sites/{id}` | `SiteDetail` | Conditions, 48 h forecast, alerts, reports, risk history |
| GET | `/api/alerts?site_id=&since=` | `AlertList` | Poll every 10 s, passing back `server_time` as `since` |
| GET | `/api/reports?site_id=` | `ReportList` | Active crew reports |
| POST | `/api/reports` | `HazardReport` (201) | Signed in. `multipart/form-data`, optional `photo` file |
| GET | `/api/photos/{id}` | image/jpeg | Use `photo_url` from a report (it's signed) |
| GET | `/api/briefings?for_date=` | `BriefingList` | Defaults to tomorrow |
| POST | `/api/briefings/generate` | `DemoAck` | Admins. Demo: generate now instead of 6 PM |
| POST | `/api/demo/lightning-replay` | `DemoAck` | Admins. Demo: storm near a site |
| GET | `/api/geocode?q=` | `GeocodeList` | Managers. US address search (OpenStreetMap) for placing a new site |
| GET | `/api/me` | `Me` | Signed-in user and their sites; plus site, member, user and admin routes in AUTH.md |

## Examples

`GET /api/sites` (one item):
```json
{
  "id": 9001, "name": "Turkey Point", "utility": "Florida Power & Light", "county": "Miami-Dade",
  "plant_type": "Nuclear", "capacity_mw": 2300, "latitude": 25.435, "longitude": -80.331,
  "timezone": "America/New_York",
  "risk": {
    "score": 8.4, "level": "extreme", "model_version": "rules-v1", "updated_at": "2026-10-17T18:45:00Z",
    "factors": [
      {"key": "heat_index", "label": "Heat index 113°F", "contribution": 2.9},
      {"key": "soil_moisture", "label": "Soil saturated after 5 days of rain", "contribution": 2.1}
    ]
  },
  "active_alert_count": 1, "top_alert": "lightning", "heat_index_f": 103.4
}
```

Lightning alert (from `GET /api/alerts`). The frontend counts down to `all_clear_at`; each new strike moves it later:
```json
{
  "id": "6f1c…", "site_id": 9001, "site_name": "Turkey Point", "type": "lightning", "severity": "danger",
  "title": "STOP WORK: lightning within 10 miles",
  "message": "Strike 3.2 mi SW at 2:42 PM. All clear in 30 minutes if no new strikes.",
  "status": "active", "started_at": "2026-10-17T18:33:00Z", "all_clear_at": "2026-10-17T19:12:00Z",
  "cleared_at": null, "meta": {"strike_count": 4, "nearest_strike_mi": 3.2, "last_strike_at": "2026-10-17T18:42:00Z"},
  "updated_at": "2026-10-17T18:42:00Z"
}
```

`POST /api/reports` form fields: `site_id`, `latitude` + `longitude` (the pin), `hazard_type`
(`wildlife | flooding | unstable_ground | downed_line | heat_illness | fire | other`),
`severity` (`low | medium | high`), `gps_latitude` + `gps_longitude` (the phone's fix; required except for admins),
optional `gps_accuracy_m`, `description`, `photo`. The reporter's name comes from their login.

## Changing the contract

1. Edit `backend/planit/models.py` (and `mock.py` so the sample data still matches).
2. `python dev.py types` and `python dev.py test`.
3. Commit `models.py`, `docs/openapi.json` and `frontend/src/lib/api-types.ts` together, and tell the other person.
